# Кермо — тренажер судноводія

Статичний тренажер для підготовки до іспиту судноводія прогулянкового/малого судна.
435 питань, розбитих на 12 тем. Працює повністю в браузері, без бекенду.

## Можливості

- **Усі питання поспіль** — 435 питань по порядку документа, з можливістю продовжити пізніше.
- **Тема поспіль** — пройти одну обрану тему від початку до кінця.
- **Тест на 10 питань** — випадкові питання з однієї або декількох обраних тем, прохідний бал 7/10.
- **Повторення помилок** — питання, у яких була помилка, автоматично повертаються за принципом
  інтервального повторення (1 день → 3 дні → 7 днів після кожної правильної відповіді поспіль),
  тож вони природньо спливають знову протягом наступних днів і тижнів.
- **Статистика** — точність відповідей загалом і по темах, історія останніх тестів.

Весь прогрес зберігається в `localStorage` браузера. Дані нікуди не надсилаються.

## Локальний перегляд

Можна просто відкрити `index.html` подвійним кліком — дані питань підключені як звичайний
`<script src="questions.js">`, тому все працює і без сервера (`file://`), і на GitHub Pages.

## Публікація на GitHub Pages

1. Створіть репозиторій на GitHub і завантажте туди весь вміст цієї папки
   (`index.html`, `styles.css`, `app.js`, `questions.json`, папку `images/`) — саме в корінь репозиторію
   (або в підпапку `/docs`, якщо налаштуєте так у Pages).
2. У репозиторії: **Settings → Pages → Source** оберіть гілку (наприклад `main`) і папку (`/root` або `/docs`).
3. Збережіть — за хвилину сайт зʼявиться за адресою на кшталт
   `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

Усі шляхи в проєкті відносні, тому сайт однаково працює і в корені домену, і в підпапці проєкту.

## Структура файлів

```
index.html      — розмітка й екрани (головна / питання / підсумок)
styles.css       — стилі
app.js           — вся логіка: питання, сесії, сховище, статистика
questions.js     — 435 питань (текст, варіанти, тема, правильна відповідь) як window.KERMO_DATA
questions.json   — ті самі дані у чистому JSON, для довідки/інших інструментів (застосунком не використовується)
images/          — 13 зображень дорожніх/навігаційних знаків, на які посилається questions.js
```

## Дані

Відповіді для 414 із 435 питань взято з офіційного документа-відповідей.
Для 21 питання (позначені `"answer_status": "неперевірено"`) відповідь визначено додатково й не
підтверджена офіційним джерелом — у тренажері такі питання позначені міткою «⚠ відповідь визначена
додатково».
